# 小红书社交模块设计文档

## 1. 模块概述

小红书社交模块负责处理与小红书平台的交互，包括用户token权限管理、发帖、评论发布和评论查询等功能。该模块为用户分身智能体的小红书宣传任务提供核心支持，确保智能体能够根据用户画像和商品信息，自动编写并发布符合小红书风格的宣传内容，并监控和回复相关评论。

## 2. 功能需求

### 2.1 核心功能
- **用户token权限管理**: 管理小红书用户token的获取、存储和使用
- **发帖功能**: 支持发布包含文案、图片的商品宣传帖子
- **评论发布功能**: 支持对帖子发布评论
- **帖子评论查询功能**: 支持查询帖子的评论列表
- **异常处理**: 处理token过期、发帖失败等异常情况

### 2.2 功能详细说明

#### 用户token权限管理
- **token获取**: Demo版采用手动输入小红书账号密码的方式，调用token获取API，获取access_token（用于后续发帖、评论操作）
- **token存储**: 获取到的token关联当前平台user_id，存储在数据库中，供用户分身智能体调用小红书相关API时直接使用，有效期内无需重复获取
- **权限范围**: 仅获取小红书账号的发帖、评论、查看评论权限，不获取其他敏感权限（如私信、账号管理）
- **安全考虑**: Demo版暂不实现token自动刷新、权限校验等复杂逻辑

#### 发帖及评论发布设计
- **发帖功能**: 用户分身智能体调用发帖API，传入token、标题、文案、商品ID及测试图片链接，完成帖子发布；Demo版不支持视频发布、话题标签、地理位置等附加功能，仅实现基础文本+图片发帖
- **评论发布功能**: 用户分身智能体可调用评论发布API，传入token、帖子ID、评论内容，完成对目标帖子的评论；支持对自己发布的帖子评论，暂不支持对他人帖子评论（简化逻辑）
- **异常处理**: 若token过期、发帖内容违规（Demo版仅做简单关键词校验），返回明确错误提示，由用户分身智能体提示用户重新获取token或修改文案

#### 帖子评论查询设计
- **查询功能**: 用户分身智能体调用评论查询API，传入token、帖子ID，分页获取该帖子下的所有评论，包含评论ID、发布者、内容、发布时间
- **联动逻辑**: 查询到评论后，用户分身智能体可根据评论内容，自主决定是否发布回复评论（如回复用户疑问、补充商品信息），实现评论互动的自动化
- **简化设计**: 暂不支持评论点赞、删除、筛选等功能，仅实现基础评论查询，满足Demo阶段任务需求

## 3. 技术架构

### 3.1 系统架构
```
小红书社交模块
├── Web层 (Spring Boot Controller)
```

```sql
CREATE TABLE xiaohongshu_token (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id VARCHAR(64) NOT NULL COMMENT '平台用户ID',
    xh_account VARCHAR(128) NOT NULL COMMENT '小红书账号',
    access_token VARCHAR(256) NOT NULL COMMENT '访问令牌',
    refresh_token VARCHAR(256) COMMENT '刷新令牌',
    expires_in INT COMMENT '有效期（秒）',
    expire_time DATETIME COMMENT '过期时间',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_id(user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

```sql
CREATE TABLE xiaohongshu_post (

    INDEX idx_user_id(user_id)
```

#### 4.2.2 具体接口

**POST /api/xiaohongshu/token/get**
- **功能**: 获取小红书用户token
- **请求参数**:
  ```json
  {
    "userId": "user123",
    "xhAccount": "xiaohongshu_user",
    "xhPassword": "password123"
  }
  ```
- **响应数据**:
  ```json
  {
    "accessToken": "access_token_123",
    "refreshToken": "refresh_token_123",
    "expiresIn": 7200,
    "expireTime": "2026-04-06T12:30:00Z"
  }
  ```

**POST /api/xiaohongshu/post/publish**
- **功能**: 发布小红书帖子
- **请求参数**:
  ```json
  {
    "accessToken": "access_token_123",
    "title": "超值推荐！iPhone 15 Pro体验分享",
    "content": "作为一名程序员，我对手机的性能要求很高...",
    "productId": "phone123",
    "imageUrls": ["https://example.com/image1.jpg", "https://example.com/image2.jpg"]
  }
  ```
- **响应数据**:
  ```json
  {
    "postId": "post_123456",
    "status": "PUBLISHED",
    "message": "帖子发布成功"
  }
  ```

**POST /api/xiaohongshu/comment/publish**
- **功能**: 发布小红书评论
- **请求参数**:
  ```json
  {
    "accessToken": "access_token_123",
    "postId": "post_123456",
    "content": "感谢分享，很有帮助！"
  }
  ```
- **响应数据**:
  ```json
  {
    "commentId": "comment_789",
    "status": "PUBLISHED"
  }
  ```

**GET /api/xiaohongshu/comment/list/{postId}**
- **功能**: 查询小红书帖子评论
- **路径参数**:
  - `postId`: 帖子ID
- **查询参数**:
  - `accessToken`: 访问令牌
  - `pageNum`: 页码（默认1）
  - `pageSize`: 每页条数（默认20，最大50）
- **响应数据**:
  ```json
  {
    "comments": [
      {
        "commentId": "comment_789",
        "xhUserId": "user_456",
        "content": "感谢分享，很有帮助！",
        "createdAt": "2026-04-06T11:00:00Z"
      }
    ],
    "total": 1,
    "pageNum": 1,
    "pageSize": 20
  }
  ```

### 4.3 业务流程设计

#### 4.3.1 Token获取流程
1. 接收token获取请求（userId、xhAccount、xhPassword）
2. 验证参数有效性
3. 调用小红书开放平台API获取token
4. 解析API响应，提取access_token、refresh_token、expires_in
5. 计算expire_time
6. 在数据库中保存token信息
7. 返回token信息

#### 4.3.2 发帖流程
1. 接收发帖请求（accessToken、title、content、productId、imageUrls）
2. 验证accessToken有效性（检查是否过期）
3. 对content进行简单关键词审核（过滤敏感词）
4. 调用小红书开放平台发帖API
5. 解析API响应，获取postId
6. 在数据库中保存帖子信息
7. 返回发帖结果

#### 4.3.3 评论发布流程
1. 接收评论发布请求（accessToken、postId、content）
2. 验证accessToken有效性
3. 对content进行简单关键词审核
4. 调用小红书开放平台评论API
5. 解析API响应，获取commentId
6. 在数据库中保存评论信息
7. 返回评论发布结果

#### 4.3.4 评论查询流程
1. 接收评论查询请求（postId、accessToken、分页参数）
2. 验证accessToken有效性
3. 调用小红书开放平台评论查询API
4. 解析API响应，获取评论列表
5. 在数据库中保存新的评论信息（增量同步）
6. 返回评论列表

#### 4.3.5 异常处理流程
1. **Token过期**: 检测到token过期，返回TOKEN_EXPIRED错误码
2. **内容违规**: 检测到敏感词，返回CONTENT_VIOLATION错误码
3. **API调用失败**: 小红书API返回错误，记录错误信息并返回API_ERROR
4. **网络异常**: 网络连接失败，返回NETWORK_ERROR
5. **参数错误**: 参数验证失败，返回PARAMETER_ERROR

#### 4.4.4 工具类
```java
// ContentValidator.java
@Component
public class ContentValidator {
    
    private static final Set<String> SENSITIVE_WORDS = Set.of(
        "违法", "色情", "赌博", "毒品", "暴力", "政治"
    );
    
    public boolean containsSensitiveWords(String content) {
        if (content == null) return false;
        String lowerContent = content.toLowerCase();
        return SENSITIVE_WORDS.stream().anyMatch(lowerContent::contains);
    }
}

// TokenManager.java
@Component
public class TokenManager {
    
    public boolean isTokenExpired(LocalDateTime expireTime) {
        return expireTime != null && expireTime.isBefore(LocalDateTime.now());
    }
    
    public LocalDateTime calculateExpireTime(Integer expiresIn) {
        if (expiresIn == null) return null;
        return LocalDateTime.now().plusSeconds(expiresIn);
    }
}
```

### 4.5 异常处理

#### 4.5.1 异常类型
- **参数验证异常**: 无效的参数、空的必填字段等
- **Token异常**: Token过期、Token无效
- **内容审核异常**: 内容包含敏感词
- **API调用异常**: 小红书API调用失败
- **网络异常**: 网络连接失败
- **数据库异常**: 数据库操作失败

## 6. 安全考虑

### 6.1 安全措施
- **密码安全**: Demo版明文传输密码仅用于测试，生产环境应使用OAuth2.0
- **Token保护**: Token存储在数据库中，不在日志中记录
- **内容审核**: 对发布内容进行敏感词过滤
- **输入验证**: 严格验证所有输入参数
- **错误信息**: 不在错误响应中暴露敏感信息

### 6.2 权限控制
- **用户隔离**: 严格验证用户ID，防止跨用户操作
- **Token权限**: 只获取必要的最小权限（发帖、评论、查看评论）
- **API权限**: 所有API都需要有效的accessToken
