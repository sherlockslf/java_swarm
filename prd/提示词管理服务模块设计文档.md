# 提示词管理服务模块设计文档

## 1. 模块概述

提示词管理服务模块负责为两种智能体类型（用户分身智能体和商品导购智能体）提供固定的系统提示词。在Demo版本中，该模块采用极简设计，将提示词硬编码在代码中，并支持在智能体启动时动态注入用户画像信息，确保智能体能够根据用户的个性化需求进行行为调整。

## 2. 功能需求

### 2.1 核心功能
- **提示词存储**: 硬编码两种智能体的系统提示词
- **动态注入**: 在智能体启动时将用户画像注入到提示词中
- **提示词获取**: 提供统一的提示词获取接口
- **格式验证**: 验证提示词格式的正确性
- **版本管理**: 支持提示词版本控制（未来扩展）

### 2.2 预置提示词内容

#### 用户分身提示词
```
你是用户的购物助手，代表用户执行购物任务和小红书宣传任务。
用户画像：{user_profile}

你的任务是：
1. 购物任务：调用商品API查询商品库、SPU-SKU关联信息及竞价数据，与导购智能体协商价格，提交购买决策供用户确认
2. 小红书宣传任务：调用小红书API获取用户token，查询目标商品信息，编写符合用户画像的宣传文案，执行发帖及评论操作，处理简单异常
3. 全程自主拆解任务、分发任务，监督任务完成，无需用户干预中间流程
```

#### 商品导购提示词
```
你是手机店的导购员，热情专业，善于推荐商品。
你可以根据用户需求推荐合适的手机，结合商品竞价数据进行价格谈判。
最低可以给用户打9折。
当用户分身智能体查询SPU-SKU信息时，需清晰说明各SKU规格差异及推荐理由。
```

### 2.3 动态注入规则
- **用户画像占位符**: `{user_profile}` 
- **注入时机**: 智能体启动时
- **注入方式**: 字符串模板替换

### 4.2 API接口设计

#### 4.2.1 通用响应格式
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

#### 4.2.2 具体接口

**GET /api/prompts/{agentType}**
- **功能**: 获取指定智能体类型的提示词
- **路径参数**:
  - `agentType`: 智能体类型（USER_AVATAR/PRODUCT_GUIDE）
- **查询参数**:
  - `userId`: string, 可选, 用户ID（用于动态注入用户画像）
- **响应数据**:
  ```json
  {
    "promptId": "user_avatar_v1",
    "agentType": "USER_AVATAR",
    "content": "完整的提示词内容（已注入用户画像）",
    "version": "v1"
  }
  ```

**GET /api/prompts/list**
- **功能**: 获取所有可用的提示词列表
- **请求参数**: 无
- **响应数据**:
  ```json
  [
    {
      "promptId": "user_avatar_v1",
      "agentType": "USER_AVATAR",
      "description": "用户分身智能体V1提示词",
      "createdAt": "2026-04-06T10:30:00Z"
    }
  ]
  ```

### 4.3 业务流程设计

#### 4.3.1 提示词获取流程
1. 子智能体管理服务调用 `/api/prompts/{agentType}` 接口
2. 服务端根据 `agentType` 查找对应的提示词定义
3. 如果提供了 `userId`，获取用户画像并注入到提示词中
4. 返回完整的提示词内容

#### 4.3.2 用户画像注入流程
1. 根据 `userId` 调用用户画像服务获取结构化用户画像
2. 将用户画像JSON转换为可读的文本格式
3. 使用字符串替换将 `{user_profile}` 占位符替换为实际用户画像
4. 返回注入后的完整提示词

#### 4.3.3 用户画像格式化
```json
{
  "name": "张三",
  "age": 28,
  "occupation": "程序员",
  "budget": 3000,
  "preferences": ["性价比高", "续航好", "拍照清晰"],
  "dislikes": ["高价低配", "系统卡顿"]
}
```

转换为文本格式：
```
姓名：张三
年龄：28岁
职业：程序员
预算：3000元
偏好：性价比高、续航好、拍照清晰
不喜欢：高价低配、系统卡顿
```

### 4.5 异常处理

#### 4.5.1 异常类型
- **提示词不存在异常**: 无效的agentType
- **用户画像获取异常**: 用户画像服务调用失败
- **用户画像格式异常**: 用户画像JSON格式不正确
- **模板替换异常**: 模板格式错误

#### 4.5.2 错误码设计
| 错误码 | 错误信息 | HTTP状态码 |
|--------|----------|------------|
| 5001 | 无效的智能体类型 | 400 |
| 5002 | 提示词不存在 | 404 |
| 5003 | 用户画像获取失败 | 500 |
| 5004 | 用户画像格式错误 | 500 |
| 5005 | 模板替换失败 | 500 |


- `PROMPT_CACHE_ENABLED`: 是否启用提示词缓存
- `USER_PROFILE_SERVICE_URL`: 用户画像服务地址

## 6. 安全考虑

### 6.1 安全措施
- **输入验证**: 严格验证agentType参数
- **XSS防护**: 对用户画像内容进行HTML转义
- **敏感信息**: 不在日志中记录完整的提示词内容
- **访问控制**: 只允许子智能体管理服务调用

### 6.2 权限控制
- Demo版本简化权限控制，所有提示词获取都需要提供有效的agentType
- 用户画像注入需要有效的userId
